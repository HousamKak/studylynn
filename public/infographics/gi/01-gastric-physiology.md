## HERO ELEMENT 1 — GASTRIC PIT DIAGRAM (centerpiece)

A labeled cross-section of a gastric pit showing all 6 cell types and their secretions, top to bottom:

| Cell type | Location | Secretion | Function |
|---|---|---|---|
| **Surface mucous cells** | Top of pit | Thick mucus + **HCO3⁻** | Mucosal barrier |
| **Mucous neck cells** | Upper neck | Mucus | Continued protection |
| **Parietal cells** | Body | **HCl** + **intrinsic factor** | Acid secretion |
| **Chief cells** | Base | **Pepsinogen** | Protein digestion |
| **ECL cells** | Body | **Histamine** | Paracrine — drives H⁺ |
| **G cells** | Antrum | **Gastrin** | Endocrine — drives H⁺ |
| **D cells** | Throughout | **Somatostatin** | Negative feedback (pH < 3) |

## HERO ELEMENT 2 — ACID SECRETION REGULATORY DIAGRAM

A large flowchart showing all 4 stimulatory pathways converging on the parietal cell's H⁺/K⁺ ATPase (proton pump).

### PARIETAL CELL (central icon with H⁺/K⁺ pump on luminal surface):

**Pathway A — Neuronal (ACh from vagus)**
- ACh → **M3 receptor** on parietal (Gq → PLC → ↑Ca²⁺) → **↑H⁺ (direct)**
- ACh → M1 on ECL → ↑ histamine release

**Pathway B — Paracrine (Histamine from ECL)** ⭐ MOST IMPORTANT
- Histamine → **H2 receptor** on parietal (Gs → ↑cAMP) → **↑H⁺**

**Pathway C — Endocrine (Gastrin from G cells)**
- Gastrin → **CCK2 receptor** on parietal (Gq → ↑Ca²⁺) → **↑H⁺ (weak direct)**
- Gastrin → CCK2 on ECL → histamine → H2 → **↑H⁺ (MAIN gastrin pathway)**

**Pathway D — Inhibitory (Prostaglandins)**
- **PGE2 / PGI2** → **EP3 receptor** on parietal (Gi → ↓cAMP) → **↓H⁺**

### NEGATIVE FEEDBACK BOX (yellow):
- **D cells** release somatostatin when **pH < 3** → ↓ gastrin release from G cells → ↓ H⁺
- ⚠️ **H. pylori blocks somatostatin** → ↑↑ H⁺ → **hypergastrinemia**

---

## CYTOPROTECTION BOX (green, right column)

- PGE2 / PGI2 → **EP4 receptor on epithelial cells** → ↑ mucus + HCO3⁻
- Forms **insoluble gel** that coats stomach → protects mucosa from H⁺
- Neutralizes acid via bicarbonate buffer
- Maintained by **adequate mucosal blood flow**

**RED HIGH-YIELD BOX:**

- D cells respond to pH < 3 → somatostatin → negative feedback
- H. pylori bypasses this feedback → hypergastrinemia + ulcers
