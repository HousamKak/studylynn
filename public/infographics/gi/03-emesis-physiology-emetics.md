## HERO ELEMENT — 4-INPUT CONVERGENCE DIAGRAM

A large central brain diagram with 4 input arrows converging on the Vomiting Center. Each input labeled with its trigger source and key receptor.

### INPUT 1 — Cerebral Cortex
- **Triggers:** sight, smell, pain, emotional
- → VC

### INPUT 2 — CTZ (Chemoreceptor Trigger Zone)
- Located in area postrema
- **Monitors blood + CSF** — **no BBB** → sensitive to circulating drugs/toxins
- **Key receptors:** D2, 5-HT3, NK-1, M1
- → VC

### INPUT 3 — STN of Vagus + Gut
- Gut afferents via vagus
- **Triggers:** GI irritation, distension, inflammation
- **Key receptors:** 5-HT3 (gut enterochromaffin cells), M1
- → VC

### INPUT 4 — Vestibular System
- Inner ear / labyrinth
- **Triggers:** motion sickness
- **Key receptors:** H1, M1
- → VC

**VC OUTPUT:** coordinated motor sequence → diaphragm + abdominal muscles + reverse peristalsis → vomiting

## EMETICS — Drugs that INDUCE Vomiting

**Indication:** toxin ingestion, foreign body ingestion (within ~2 hours)

### CARD 1 — Central Emetics

**A. Apomorphine** ⭐ (dogs)
- **Mechanism:** D2 agonist (+ μ-opioid agonist) at CTZ
- **Route:** SC / IM
- **Onset:** emesis in **5–10 min**
- **Species:** dogs (first choice)

**B. Xylazine** ⭐ (cats)
- **Mechanism:** α2 agonist
- **Route:** IM
- **Species:** cats (first choice — apomorphine ineffective in cats)

### CARD 2 — Peripheral Emetics (Local Irritants)

- **Ipecac** (syrup of ipecac)
- **H2O2** (3% hydrogen peroxide)
- **Hypertonic NaCl**
- **Mechanism:** direct irritation of gastric mucosa
- **Use:** treat intoxication (especially when no apomorphine/xylazine available)

---

**⚠️ CONTRAINDICATIONS FOR EMETIC USE (red box)**

DO NOT induce emesis if:
- Patient is **unconscious / anesthetized / depressed**
- Active **convulsions** / seizures
- **No gag reflex**
- Ingestion of **corrosives** (acids/alkalis — further damage on way back up)
- Ingestion of **detergents** (foaming → aspiration risk)
- Species that cannot vomit (ruminants, horses, rodents, rabbits)
- Time elapsed > 2 hours (toxin already absorbed/passed)

## ANTIEMETIC CLASS PREVIEW (yellow strip, points to next poster)

8 antiemetic classes work by blocking receptors at the inputs above:

| Class | Target | Example |
|---|---|---|
| Phenothiazines | D2 (CTZ + VC) | Chlorpromazine, acepromazine |
| Antihistamines | H1 (vestibular) | Dimenhydrinate, promethazine |
| Antimuscarinics | M1 | Scopolamine |
| Metoclopramide | D2 + 5HT3 + 5HT4 | Metoclopramide |
| 5HT3 antagonists | 5HT3 (CTZ + gut) | Ondansetron |
| Glucocorticoids | Adjunct | Dexamethasone |
| NK-1 antagonists | NK-1 (VC, vagus) | Maropitant |
| Cannabinoids | CB1 | Dronabinol |
