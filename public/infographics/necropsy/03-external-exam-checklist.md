### THIS POSTER — Specific Content

**TITLE (top band):** External Exam & Pre-Incision Checklist

**PHILOSOPHY BOX (green, top):** The external exam is **pure data** — the ONLY look before evidence is destroyed. Once you incise, bruising spreads, blood leaks, gas escapes, contamination begins.

## LEFT — STRUCTURED EXTERNAL EXAM (body diagram with callouts)
- **Overall impression** (before touching): good BCS + sudden death → acute; cachexia → chronic systemic disease
- **Body condition & hydration:** skin tenting + sunken eyes + dry mucosa → dehydration
- **Integument:** symmetrical alopecia → endocrine; multifocal crusting → ectoparasites; nodules → neoplasia
- **Orifices:** foam at mouth → pulmonary edema; nasal hemorrhage → clotting disorder; rectal prolapse → chronic diarrhea
- **Nails / claws / hooves:** broken → struggle/seizure; overgrown → neglect
- **Injection sites:** swelling/mass → injection reaction or **vaccine-site sarcoma (cats)**

## RIGHT — THE 7-POINT PRE-INCISION CHECKLIST (numbered)
1. **Confirm identification** (species/breed/sex/age/microchip) — misidentification = invalid report
2. **Record time of death + necropsy** — needed to interpret autolysis/rigor/clotting
3. **Decide necropsy type** (diagnostic / herd / forensic / surveillance)
4. **Summarize history + list differentials** (3 lines max)
5. **Decide what must be sampled FIRST** (before contamination)
6. **Assess PPE / zoonotic risk** (rabies, TB, Salmonella, Brucella)
7. **Prepare labeled containers**

**RED HIGH-YIELD BOX:**
- Necropsy is **IRREVERSIBLE** — the checklist forces diagnostic intention, sampling foresight, legal awareness, infection control
- External exam is your ONLY chance to read the whole-body lesion pattern

**GRAY FOOTER:** observe before cutting · ID + times + type + history + first samples + PPE + labels.
