### THIS POSTER — Specific Content

**TITLE (top band):** Report Writing & the 5 Lesion Categories

## LEFT — REPORT WRITING (blue)
- **THE core rule (red highlight):** separate **DESCRIPTION** from **INTERPRETATION**. Bad: "the liver was septic." Good: "enlarged with multifocal pale raised nodules 0.5–2 cm" → then "consistent with bacterial abscessation"
- **Describe a lesion by 7 features:** location, size, shape, color, distribution, consistency, severity
- **Morphologic diagnosis formula:** Severity + Duration + Lesion type + Organ + Distribution → "severe acute diffuse fibrinosuppurative bronchopneumonia"
- **End every report:** primary disease + mechanism of death + contributing conditions; list differentials honestly
- **Pattern > single lesion:** pale liver + big spleen + petechiae + dark blood = septicemia

## RIGHT — THE 5 LESION CATEGORIES (green)
1. **Inflammatory** — serous → fibrinous (bacterial) → suppurative (pyogenic) → hemorrhagic
2. **Circulatory** — congestion (dark/heavy) · hemorrhage (petechiae→ecchymoses→hematoma) · edema (wet/heavy)
3. **Degenerative** — fatty change (pale/greasy) · necrosis (focal→diffuse)
4. **Neoplastic** — benign (demarcated/slow) vs malignant (invasive/metastatic/destructive)
5. **Mechanical** — GDV/torsion/hernia/obstruction → distension, ischemia, **SHARP transition zones**

**YELLOW — CHRONICITY:** Acute = hyperemia/hemorrhage/edema/fibrin · Chronic = fibrosis/adhesions/scarring/nodularity.

**RED HIGH-YIELD BOX:**
- Describe first, interpret later (the most common error is mixing them)
- Reason every case in sequence: history → gross → distribution → pathophysiology → differentials → sampling → cause of death
- Always distinguish autolysis / hypostasis / decomposition from disease
