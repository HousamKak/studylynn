### THIS POSTER — Specific Content

**TITLE (top band):** GI Tumors & High-Yield Comparisons

## INTESTINAL TUMORS (blue)  — ~90% are epithelial + lymphoma
- **Adenoma / adenocarcinoma:** polypoid (benign or malignant) vs ulcerative/penetrating (always malignant)
- **Lymphoma:** **cats >> dogs**; localized (enterectomy+chemo) / diffuse / multilocalized (chemo)
- **Canine granulomatous lymphoma:** extremely aggressive → perforation + rapid metastasis (~1 wk survival)

## THE TESTED COMPARISONS (yellow grid)
| Compare | Key distinction |
|---|---|
| **Rotavirus vs Coronavirus** | Rota = villus tip → regenerative, transient (~7 d). Corona = lower villus → severe effacement/fusion, ~100% mortality |
| **Crypto vs Coccidia** | Crypto = surface (no penetration), zoonosis, PCR. Coccidia = penetrate + destroy enterocytes |
| **ETEC toxins** | LT = adenylate cyclase (slow/long). ST = guanylate cyclase (fast/short) |
| **Lawsonia vs Johne's** | Lawsonia = crypt proliferation, thickened folds, Warthin-Starry. Johne's = chorion macrophages, encephaloid folds, Ziehl-Neelsen |
| **Salmonella forms** | Septicemic (DIC) · Acute (typhlocolitis) · Chronic (ulcer+stenosis→megacolon) |
| **Parvovirus target** | Crypt enteroblasts → hyporegenerative atrophy + Peyer's depletion; killed by superinfection |
| **FIP wet vs dry** | Wet = humoral → yellow effusion. Dry = cellular → serosal pyogranulomas (both Type III vasculitis) |
| **Diarrhea localization** | Watery = small intestine. Soft + mucus = colon |
| **Dangerous larvae** | S. vulgaris (mesenteric artery) · Echinococcus (hydatid) · cestode larvae (cysts) |

**RED HIGH-YIELD BOX:**
- ~90% of intestinal tumors = epithelial + lymphoma; lymphoma cats >> dogs
- Ulcerative/penetrating epithelial tumor = always malignant
- Memorize the stain pairs: Warthin-Starry (Lawsonia) vs Ziehl-Neelsen (Johne's) vs PAS (Boxer HUC)
