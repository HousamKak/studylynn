### THIS POSTER — Specific Content

**TITLE (top band):** Infectious Enteritis I — Enterocyte Diseases

**ORGANIZING PRINCIPLE (green):** enteric agents attack by **target layer**: enterocyte → crypt → chorion → serosa (muscularis spared). This poster = the **enterocyte** layer.

## HYPERSECRETION / FLUID LEAK (blue)
- **ETEC** — E. coli, very young achlorhydric piglets/calves; pili adhesion + **LT (adenylate cyclase, slow/long)** + **ST (guanylate cyclase, fast/short)** → hypersecretory yellow-white diarrhea; near-normal histology
- **Type A enterotoxemia** — C. perfringens Cpe pore toxin → tight-junction loss → hypersecretion

## MICROVILLUS REMOVAL / SURFACE (blue)
- **EPEC** — attaching-effacing effacement (intimin); opportunistic — find the primary cause
- **Cryptosporidiosis** — stays on SURFACE (no penetration), **zoonosis**, PCR, hard to treat
- **Giardiasis** — microvillus-adhering flagellate → malabsorption + osmotic diarrhea (chronic, foul)

## ENTEROCYTE DESTRUCTION (blue)
- **Rotavirus** — villus **TIP** (mature cells) → regenerative, **transient** (~7 d), mild
- **Coronavirus/TGE** — **lower villus** → severe effacement + fusion, ~100% mortality, lasting maldigestion
- **Coccidiosis** — penetrate + destroy (schizogony→gametogony)
- **Swine dysentery** — Brachyspira, mucus-tropic, **colon only** → mucohemorrhagic colitis

**ENTEROTOXEMIA TYPES (yellow):** A=nervous · B=lamb dysentery · C=hemorrhagic enteritis · D=**pulpy kidney** (ε toxin → glycosuria → rapid kidney autolysis).

**RED HIGH-YIELD BOX:**
- LT = adenylate cyclase / ST = guanylate cyclase
- Rota = tip/transient; Corona = lower-villus/severe
- Crypto = surface/zoonosis/PCR vs coccidia penetrate
- Pulpy kidney: kidney autolyzes faster than liver = enterotoxemia clue

**GRAY FOOTER:** enterocyte diseases = hypersecretion (ETEC), surface/microvillus (crypto/EPEC/giardia), destruction (rota/corona/coccidia); enterotoxemia A–D.
